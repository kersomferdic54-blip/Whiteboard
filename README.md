# Digital Whiteboard

A full-screen digital whiteboard and drawing app for Android, built for touch and stylus input. It feels like a physical board, with a clean, minimal interface that keeps the canvas front and center.

## Features

- **Three board types:** White, Black, and Green (classroom) boards
- **Smooth drawing:** low-latency strokes with finger or stylus, plus pressure sensitivity where supported
- **Tools:** Pen, Brush, Eraser, Undo, Redo, Clear
- **Adjustable properties:** stroke size and opacity for each tool
- **Color picker:** full RGB spectrum with hue, saturation, brightness, HEX/RGB input, and recent colors
- **Floating toolbar:** a draggable, semi-transparent circular button that expands into a compact tool card
- **Saved boards:** gallery with thumbnails, names, dates, and board types. Open, rename, copy, or delete boards
- **Editable saves:** boards are stored as individual strokes (not screenshots), so they reopen exactly as you left them
- **Settings:** floating button opacity, toolbar opacity, and button size
- **Google Login:** UI placeholder only ("Google Sign-In coming soon")

## Getting Started

1. Clone the repository
2. Open it in **Android Studio** (Hedgehog or newer)
3. Let Gradle sync, then run on a device or emulator
